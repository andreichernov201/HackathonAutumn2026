# Regula AI

Стартовая страница Regula AI. Это рабочий фронтенд, но сервер с нормативной базой и генерацией документов пока не подключён.

## Запуск на компьютере

Нужен Node.js 24 и npm.

```bash
npm ci
npm run dev
```

Vite покажет адрес страницы. Обычно это `http://127.0.0.1:5173/`.

Проверить сборку:

```bash
npm run build
```

## Запуск в Docker

```bash
docker compose up --build -d
```

После сборки страница будет на `http://127.0.0.1:8080/`. Остановить контейнер: `docker compose down`.

Если на Mac после установки Docker Desktop терминал ещё не находит команду `docker`, можно запустить Compose напрямую: `/Applications/Docker.app/Contents/Resources/cli-plugins/docker-compose -f compose.yaml up --build -d`.

Контейнер отдаёт готовые статические файлы через Nginx. Бэкенда внутри нет.

## Что уже работает

- Адаптивная стартовая страница, меню и четыре быстрых действия.
- Поле запроса: Enter отправляет, Shift+Enter переносит строку.
- Выбор файла и локальная история диалогов с возможностью её очистить.
- Разделы «Документы», «Проверка» и «База знаний» с пустыми состояниями.

Запросы сохраняются в браузере. Содержимое файла пока никуда не загружается и не хранится — остаются только имя, размер и тип. Приложение не выдаёт вымышленные нормативные ответы и документы.

## GitHub

Проект лежит в приватном репозитории [HackathonAutumn2026](https://github.com/andreichernov201/HackathonAutumn2026). В нём есть `.gitignore` и проверка GitHub Actions. При push в `main` или `dev`, а также при pull request в эти ветки она собирает приложение и Docker-образ.

`main` — готовая версия. `dev` — общая ветка разработки. Для новой задачи создаю ветку от `dev`, затем открываю pull request обратно в `dev`. Готовые изменения переношу из `dev` в `main` через pull request.

Коммиты называю коротко: `добавлено: ...`, `фикс: ...`, `изменено: ...`.
