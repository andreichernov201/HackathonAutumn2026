# Regula AI

Прототип Regula AI: диалог, источники, черновик распоряжения и рабочая панель. По умолчанию работает явно помеченное демо на трёх выдержках из условий кейса. Сервер с нормативной базой, генератор DOCX и согласование пока не подключены.

## Запуск на компьютере

Нужен Node.js 24 и npm.

```bash
npm ci
npm run dev
```

Vite покажет адрес страницы. Обычно это `http://127.0.0.1:5173/`.

Проверить сборку:

```bash
npm run build
```

## Запуск в Docker

```bash
docker compose up --build -d
```

После сборки страница будет на `http://127.0.0.1:8080/`. Остановить контейнер: `docker compose down`.

Если на Mac после установки Docker Desktop терминал ещё не находит команду `docker`, можно запустить Compose напрямую: `/Applications/Docker.app/Contents/Resources/cli-plugins/docker-compose -f compose.yaml up --build -d`.

Контейнер отдаёт готовые статические файлы через Nginx. Бэкенда внутри нет.

## Что уже работает

- Адаптивная стартовая страница, меню и четыре быстрых действия в прежнем стиле.
- Поле запроса: Enter отправляет, Shift+Enter переносит строку.
- Выбор файла и локальная история диалогов с возможностью её очистить.
- Структурированные ответы: цитаты, прогресс, уточнение, карточка проекта и результат предварительной проверки.
- Сворачиваемая панель «Источники / Документ / Маршрут». Цитата открывает конкретную выдержку в панели.
- Связанный сценарий: спросите о номере распоряжения, затем выберите «Создать проект распоряжения», заполните тему и руководителя справа и отправьте «Продолжить». Поля и диалог меняют один проект в состоянии сессии. Также допустим ответ в чате: `Тема: ...; Руководитель: ...`.
- Разделы «Документы», «Проверка» и «База знаний» пока с пустыми состояниями.

История, проект и состояние панели сохраняются в `localStorage` этого браузера. Выбранный файл не загружается и не читается; сохраняются лишь имя, размер и тип. Выдержки являются данными демонстрации из условий кейса, а не проверенными оригиналами: оригиналы и версии документов нужно загрузить и сверить. Проект в панели — черновик, не DOCX. Номер не присваивается, маршрут по главе 10 Инструкции не строится, согласование не проводится.

Для переключения на будущий серверный адаптер задайте `VITE_CHAT_BACKEND=api` при сборке. Адаптер отправляет типизированный JSON на относительный `POST /api/chat` с `conversationId`, историей и контекстом проекта. Этот режим требует собственного FastAPI сервера: в текущем Docker Compose его нет. Ollama и модель не вызываются из браузера. Файлам понадобится отдельная защищённая загрузка.
